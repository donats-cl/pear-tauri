# Pear Desktop (Tauri Version)

## 📌 Обзор проекта
Это облегченная версия Pear Desktop, построенная на базе **Tauri v2**. Вместо полноценного порта приложения, проект представляет собой «тонкую оболочку» над `music.youtube.com` с внедрением пользовательской функциональности через JS-бандл.

### Основной стек:
- **Backend:** Rust (Tauri v2) — управление окном, системные разрешения, проксирование запросов.
- **Frontend (Injection):** TypeScript + Vite (IIFE bundle) — логика плагинов, внедряемая в страницу через `initialization_script`.
- **Стилизация:** CSS-переменные YouTube Music + `adoptedStyleSheets`.

---

## 🏗️ Устройство приложения

### 1. Rust-слой (`src-tauri`)
- **Окно:** Создается динамически в `main.rs`, что позволяет точно контролировать порядок внедрения скриптов.
- **Инъекции:** Скрипт из `inject/dist/inject.iife.js` встраивается в WebView до загрузки страницы.
- **Команды:** Rust используется для обхода CORS (например, загрузка обложек или текстов песен), предоставляя JS-слою доступ к сети через `invoke`.

### 2. JS-слой (`inject`)
- **Core:** Мини-ядро для управления CSS и ожиданием готовности Player API YouTube Music.
- **Features:** Модульная архитектура плагинов:
    - `adblock.ts`: Перехват `JSON.parse` и `Response.json` для вырезания рекламных данных.
    - `album-color.ts`: Анализ цвета обложки и динамическое обновление CSS-переменных интерфейса.
    - `lyrics.ts` (в разработке): Поиск и синхронизация текстов песен.
    - `ambient-mode.ts`: Свечение вокруг плеера по цветам видео/обложки.
    - `discord-rpc.ts`: Discord Rich Presence («Слушает …»); IPC с Discord — в `src-tauri/src/discord_rpc.rs`.
    - `history.ts` / `history-page.ts`: история прослушиваний и страница «История» в боковом меню.
      Хранится в SQLite (`<app data>/com.pear.music/history.sqlite3`, `src-tauri/src/history.rs`):
      `tracks` (клип и песня — один трек), `track_videos` (videoId → трек), `plays` (одна узкая строка
      на прослушивание). Итоги по трекам ведут триггеры. ~69 МБ и запросы до ~100 мс на 1 млн прослушиваний
      (замер: `cargo test --release -- --ignored --nocapture`).
- **Сборка:** Vite собирает всё в один IIFE-файл, который исполняется в контексте страницы.

## 🚀 Масштабирование и развитие

### Добавление новых функций:
1. Создать новый файл в `inject/src/features/`.
2. Инициализировать его в `inject/src/entry.ts`.
3. Если функция требует доступа к сети (CORS) или системным ресурсам $\rightarrow$ создать команду в `src-tauri/src/main.rs`.

### Оптимизация:
- **Конфигурация:** Переход с `localStorage` на `tauri-plugin-store` для синхронизации настроек между Rust и JS.
- **Производительность:** Замена `setInterval` на более точные `MutationObserver` для отслеживания изменений в DOM.

### Возможные расширения:
- **Медиаклавиши:** Интеграция `tauri-plugin-global-shortcut` для управления плеером из ОС.
- **Трей:** Добавление управления приложением через системный трей.
- **Автообновление:** Использование `tauri-plugin-updater` для обновления JS-бандла без пересборки всего приложения.
